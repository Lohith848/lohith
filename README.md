# Birthday wish to your ❤️ one's 

## Project Description

Birthday Wish is a simple and interactive web application designed to send personalized birthday wishes to your loved ones. This project uses HTML to create a beautiful, user-friendly interface that makes it easy to celebrate special moments with friends and family.

## Features

- 🎉 **Interactive Birthday Wishes** - Send personalized birthday messages
- 💝 **Beautiful UI** - Clean and attractive design for a memorable experience
- 💌 **Easy to Use** - Simple interface for users of all ages
- 🎨 **Customizable Messages** - Create unique wishes for special people
- ⚡ **Fast and Lightweight** - Quick loading times and smooth performance

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Lohith848/birthday_wish.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd birthday_wish
   ```

3. **Open the application:**
   - Simply open the `index.html` file in your web browser
   - Or double-click the HTML file to launch it

## Usage

1. Open the application in your web browser
2. Fill in the recipient's name and your personalized birthday message
3. Customize the message with colors and styles as desired
4. Share the birthday wish with your loved one
5. Enjoy celebrating their special day!
